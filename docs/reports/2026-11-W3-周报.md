## 6. 复验命令与说明

```powershell
python -m pytest -p no:warnings
python -m ruff check .
python tools/check_boundaries.py
python tools/check_guard_words.py
```

评测以每组独立临时目录中的 SQLite 库为起点，先 seed，再执行
`eval/run_eval.py --dataset v2 --retriever <bm25|koosearch> --llm <offline|modelarts>`。
数据目录、报告目录和词表通过 MEDPAL_DATA_DIR / MEDPAL_DB / MEDPAL_REPORT_DIR / MEDPAL_LEXICON 指定。
PR #94 的详细修复与验收记录见其 `docs/evidence/2026-11-16-c5-review.md`。
云端历史证据位于 PR #96 的 `docs/evidence/2026-11-15-*.md`；尚未合入时应从对应 PR 查看。
