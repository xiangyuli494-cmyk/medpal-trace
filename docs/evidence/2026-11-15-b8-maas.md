> 采集人：队长 xiangyuli494-cmyk　采集机：本机（Windows，小写盘符直连 api.modelarts-maas.com 可通）

## 1. 一句话结论

**MaaS 的 DeepSeek 走 `/v2` 端点，不走 `/v1`。** 预置服务 `DeepSeek-V4.1-Flash-1017` 开通后，
`https://api.modelarts-maas.com/v2/chat/completions` + `model=deepseek-v4.1-flash-1017` 返回 200 与中文正文；
同一把 key 打 `/v1/chat/completions` 会得到 `ModelArts.81016 The model ... is not available with api url`，
打 `/inference/v1/chat/completions` 会得到 `APIG.0101`。这三个地址的区别是本节唯一要记住的事。

  -H 'Content-Type: application/json' \

## 6. 遗留与风险

1. **延迟**：单次 12.6s（其中 reasoning_tokens=96），压测（B12 50 并发）必须按这个量级设超时，
   否则 P95 全是超时假象；建议 pipeline 侧把 LLM 超时从默认值调到 30s，并在压测里单列 LLM 组与 offline 组。
2. **计费**：`DeepSeek-V4.1-Flash-1017` 输入 ¥2.00/百万 tokens、输出 ¥8.00/百万，
   缓存命中输入 ¥0.20。60 条评测跑一遍约 2 分钱，压测 50 并发 × 100 次要按量估，别开着不关。
3. **未开通的服务一律 403**：想换 GLM-5.3 / openPangu 做对比，要先在控制台逐个「开通服务」，
   否则代码侧再对也是 81004。
4. 早期文档 `docs/evidence/2026-11-08-maas.md`（余额 0 → 模型列表空）与本文件不是矛盾：那是未开通+无余额时点，
   这是开通后时点。以本文件为准，两份都保留以便说明演进。
