# PR #96 复审修订与本地镜像验证（2026-11-17）

## 评审意见的处理

| 意见 | 修订 |
| --- | --- |
| 旧 0.1.0 镜像可能缺 psycopg，节点还会复用缓存 | 部署改用 0.1.1 与 Always；部署前必须构建、推送并记录 digest，不复用旧 tag |
| 桶名不一致 | 默认统一为已有真机证据的 medpal-trace-cn4；当前桶存续和访问权需部署时核验 |
| 内存请求过小 | 改为 128Mi；节点容量不足时释放或扩容，不再降低请求 |
| 私有 SWR 凭据被注释 | 启用 swr-secret，README 补创建凭据前置步骤 |
| 数据库抖动导致存活探针误杀 | 新增无数据库依赖的 /livez，/health 继续作为就绪探针；Docker HEALTHCHECK 同步调整 |
| 运行镜像没有 OBS SDK | 构建阶段编译 crcmod 等 wheel，运行阶段安装 OBS SDK 与 psycopg，不保留编译器 |
