## 4. 充钱后这样补验收

```bash
# 1) 部署
kubectl apply -f deploy/k8s/
kubectl -n medpal rollout status deploy/medpal-api

# 2) 一键验收（本 PR 新增）
bash scripts/check_cce.sh
# 或手动指定内网 ELB
ELB=192.168.0.217 bash scripts/check_cce.sh
```

`check_cce.sh` 会：

1. `kubectl -n medpal get pods -o wide`，任一 pod 非 Running 或非全 READY 即 FAIL
2. 从 `svc/medpal-api-lb` 取 LoadBalancer IP（或 `ELB=` 手动指定）
3. **集群外** `curl http://<ELB>:8000/health`，非 200 或 `ok!=true` 即 FAIL
4. 证据落到 `docs/evidence/<timestamp>/`（pods.txt / health.json / summary.md）
